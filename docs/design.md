# 粒子表情：界面与动作约定

## 主屏

全屏暗蓝 `#040d20`，只保留一个复杂粒子角色和一个输入栏。不要 Logo、导航、介绍、头像、传统气泡列表或装饰性文案。回答在角色周围随机安全位置浮现，然后淡出。

视觉依据是用户提供的 `src/images/` 七张大肥鱼原画，而非通用 AI 球形笑脸。保留蓝发、暖色皮肤、白色服饰与原画笔触；白衣不能被当成背景删除。不加紫色渐变、设备框或其他画风。

## 原画与运动

- 顺序是**分层／补底 → 原色联动 → 粒子化 → 对话调度**。不能用通过测试替代分层与中间帧视觉验收。
- 当前约 5.9 万颗点。主体、头发和皮肤固定；运动粒子保留原画提取的 RGBA、材质、三角形和重心坐标。
- 禁止矩形像素重分配、逐帧换色、统一口红颜色、额外描粗眼线或扩大肤色洞来掩盖绑定错误。
- 眼睑笼与原画开口共同驱动遮挡，虹膜／眼白保持原位置，不压扁或整片淡出。嘴内、上下唇使用相同口型轮廓，闭口开口面积归零。
- 嘴内以轻声原画为采样基准，使用蓝噪声避免压缩条码；所有部件共用点核和面积规则，不额外加粗／提亮嘴部。
- 本轮优先眨眼、轻声说话。眼褶保持原笔触厚度，眼角和发际线不能被带走。思考／好奇小幅抬眉；暂不叠加视线漂移和独立舌头动作。
- 按短语和标点停顿，不逐字机械张嘴；停止后平滑收口。只是文字节奏，不是语音音素同步。
- 主体补底来自同一基准图的分材质延展与局部克隆，不搬运未对齐的其他表情皮肤。PNG 被遮住的位置无法精确还原，仍需人工复核。

## 渲染与生命周期

WebGL 每帧先更新少量局部顶点和原画 alpha 遮挡缓冲，再一次批绘粒子。主屏不画原图 RGB 贴片，不下载七张 PNG 播放。像素比限制为 2；纹理尺寸有上限。

不支持 WebGL、上下文丢失或运行时绘制失败时降级 Canvas；降级也用相同网格、原画蒙版和绑定，固定点场缓存、局部低帧率更新。素材加载失败明确显示重试，不能静默切换公式脸。页面隐藏暂停，减少动态效果时不运行动作循环，销毁时释放 RAF、监听器与绘图资源。

## 独立校对页

`/preview/character` 是工作校对工具，不给极简主屏增加导航或介绍。提供补底图、原色／粒子联动、五官放大、动作进度、原始参考和透明图集。原色与粒子共用网格；先确认原色动作，再判断颗粒效果。

重点看发际线、眼角、睫毛、上下唇、鼻尖和领口保护区。自动分层不等于人工 PSD，局部笔触仍可能需要调整；不可据测试数量宣称视觉问题全部解决。

## 浮现回答

- 默认无问候或示例话题；用户发消息后才出现回答。
- 默认 1–2 条短句、最多 3 条，无头像、对话框或大面积底色。
- 位置按视口和角色轮廓划分安全区，带稳定随机扰动，避免遮住角色、输入栏和其他回答。
- 按长度停留 6–45 秒；悬停、键盘聚焦和页面隐藏时暂停消失计时。
- 长内容可在文字区域滚动，小屏主要使用角色上下空间。第三条出现时最早一条提前淡出，不堆成列表。
- 错误、停止和重试仅在需要时出现；设置入口低调放在输入栏里。

## 可用性底线

中文输入法合成时 Enter 不发送，Shift + Enter 换行。设置使用原生 dialog、焦点约束与恢复。密钥仅在服务端或页面内存；刷新后清除，不落浏览器持久存储。文字淡出不删除模型上下文和辅助阅读记录。

验证手机短屏、320／768／1024／1440px、键盘、素材错误、降级、动态偏好、SSE、上下文和对话生命周期；角色验证包含源坐标重建、网格不翻折、固定 RGBA／主体、真实 GPU 像素与中间帧保护区。axe 只辅助无障碍检查，技术回归不等于完整人工审计或原画风格验收。
